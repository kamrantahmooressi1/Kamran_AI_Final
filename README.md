## 🛠 Tech Stack & Design
- **Core Framework:** React (via CDN)
- **Styling:** Custom Vanilla CSS (Midnight Navy & Purple Palette)
- **Interactivity:** React State, Intersection Observer (Scroll Reveal), Canvas API (Particle System)
- **Icons:** Lucide-React
- **Deployment:** GitHub Pages

---

## 🏛 Navigation & Features
- **Global Sustainability Feed:** A live-action ticker at the top providing real-time links to global breakthroughs in EV technology, ESG regulations, and corporate carbon-neutrality pledges.
- **Strategic Domain Badges:** High-level categorization of expertise in AI Engineering, Sustainability, and Microeconomic Modeling.
- **Interactive Coursework Portfolio:** An accordion-based repository of university coursework, including:
    - **ECON 305:** Microeconomic analysis of Amazon's EV logistics transition.
    - **SUST 401:** Research on Banerjee’s development models and shareholder value.
    - **MGMT 342:** AI-architected development and Gamma case study.
- **Dynamic Background:** A custom-built particle system and scroll-reveal animations to enhance user engagement.
